# IQC 晶圓 CP 數據審核系統 ( Story Points )

**文件版本：** 1.0
**製作日期：** 2026-04-24
**專案名稱：** IQC Wafer CP Review System MVP

---

## 專案概述

本專案為一套 IQC 晶圓 CP 數據智能審核平台，取代現有 Excel VBA 手動審核流程，實現多廠家格式自動識別、智能審核、SPC/Cpk 分析、AI 異常偵測及廠商績效管理。

### 核心價值
- 自動化審核：多廠家格式自動識別、Q1/Q2/Q3 規格自動檢驗
- 數據驅動：SPC 管制圖、Cp/Cpk 製程能力分析、歷史趨勢追蹤
- AI 智能：異常偵測、審查摘要自動生成、風險預警
- 靈活擴展：廠商格式模板可配置、不限廠家數量

### 技術架構
- **前端：** React 18 + TypeScript + Tailwind CSS + Vite
- **後端：** Python FastAPI + SQLAlchemy + Alembic
- **資料庫：** MySQL
- **AI 服務：** DeepSeek（異常偵測 + 審查摘要）
- **部署：** Docker
